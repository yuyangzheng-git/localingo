项目介绍

一个 Chrome 扩展 + 本地翻译引擎 + 自托管学习中心。它把「读懂英文」和「记住英文」接在同一条路上：

  1. 读 — 网页保持英文原文，逐段附上简体中文，随滚动翻译，动态内容也会跟着更新。
  2. 查 — 选中单词或短语即离线查词，词形还原（studies → study）与来源一目了然。
  3. 收 — 收藏保留你选中的释义、所见原句与来源链接，同一义项再次遇见只增语境。
  4. 记 — 先回忆再看答案，按 忘记 / 困难 / 记得 / 很熟 评分，间隔重复到长期记忆。

功能

  • 离线词典

    选词即查，完全离线（ECDICT 词库，MIT 许可），不联网、不经翻译服务器。

  • 学习阅读

    保留英文原文的阅读模式；每段末尾一个「译」，点一下只译该段。

  • 生词本 · 真实语境

    每一条词都带着你遇见它的原句与来源，检索、筛选、编辑、回收区一应俱全。

  • 间隔复习

    固定阶梯 10 分钟 → 1/3/7/14/30/60 天，默认每天 5 个新词，随时暂停。

  • 学习中心 & 侧栏

    集中管理生词、收藏句子与复习；侧栏固定查词与当前页生词。

  • 你的数据

    JSON 备份 / 恢复、Anki TSV 导出，无需登录即可使用；可选登录后与服务器同步。
