INSTALL ON YOUR MAC

One command.
Then add it to Chrome.

For Apple Silicon Macs with Chrome. The installer sets up local translation, downloads the model once, and starts it whenever you log in. No token, no terminal afterwards.

curl -fsSL http://101.35.6.63:8083/install.sh | bash
  1. 01 / RUN

    Paste it into Terminal.

    Open Terminal (⌘ Space, type “Terminal”), paste the command and press Return. The first run downloads about 4 GB, then test-translates a sentence to make sure the model works.

  2. 02 / LOAD

    Add the extension.

    The installer opens chrome://extensions and shows the chrome-extension folder in Finder. Turn on Developer mode and drag the folder onto the page. Only needed once.

  3. 03 / READ

    Start reading.

    Translation and word lookup work right away. Sign in to the learning center to keep words and review them on any device.
