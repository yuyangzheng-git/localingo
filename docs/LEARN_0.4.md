# LocaLingo Learn 0.4：实现与验收记录

对应 [PRD](PRD_ENGLISH_LEARNING.md)。日期 2026-10-20。分支 `feat/learn-0.4`。

## 与 PRD 的差异（按需求方决定）

- **同步与网页版提前到 0.4**：PRD 把跨设备同步列为 P2 / M01。需求方明确要求“同步到自己的服务器”并能“通过网页配合”，因此 0.4 包含 `server/`（FastAPI + SQLite，Docker 部署）和同一套学习中心的网页版。数据仍以扩展本地 IndexedDB 为准；同步是可选的，登录前不发送任何内容。
- **P1 未做**：上下文释义（A01）、长难句解释（A02）、理解检查（A03）、逐句朗读（L01）、熟悉词提示（V03）。因此选词操作条只提供“查词 / 翻译 / 收藏句子”，没有“解释句子”。
- **收藏句子** 在 0.4 中可用（PRD §7.2 第 4 步），没有 AI 分析快照。

## 同步（超出 PRD 0.4 范围）

- 本地服务器端到端：网页版保存 `see` 并复习 → 服务器收到条目、语境、卡片、复习事件；扩展登录后上传本机 `studies`、下载 `see`，两边一致。
- `server/` 18 个 pytest：登录与限流、令牌失效、LWW 与分页、游标重置、用户隔离、请求校验、词典 API、只开放网页文件、CORS 只允许扩展。
- **Docker 镜像未在本机构建验证**（这台 Mac 没有安装 Docker）。
