# LocaLingo · UI 与交互检查

检查日期：2026-10-20（Australia/Sydney）。项目目录：`/Users/yuyangzheng/project/localingo`。

## 产品方向

把 LocaLingo 做成一个安静、可控的本地阅读助手。常用操作围绕当前页面展开：确认页面 → 选择阅读方式 → 开启翻译 → 查看反馈 → 随时恢复原文。服务器配置属于首次使用和排错流程，不应占据日常操作的中心。

界面使用暖白、深绿和适量留白，避免与网页正文争夺注意力；支持系统深色模式和减少动态效果偏好。中文是操作语言，英文用于品牌和语言方向。

## 已发现的问题与本次实现

| 问题                                             | 对用户的影响                             | 本次调整                                           |
| ------------------------------------------------ | ---------------------------------------- | -------------------------------------------------- |
| 显示的是全局上次翻译统计                         | 换页面后仍可能看到另一个页面的数据       | 只查询当前标签页，显示标题、域名和本页计数         |
| 点击翻译后立即关闭弹窗                           | 用户看不到处理状态，也不清楚是否已经开始 | 弹窗保留，显示处理中、已处理、等待滚动等状态       |
| 只有一个翻译开关，文字无法区分后台工作与阅读状态 | 容易误解“开启”意味着仍在不停计算         | 分别显示“翻译此页”“停止并恢复原文”“恢复原文”       |
| 失败后缺少局部恢复入口                           | 用户只能重新开始，已完成内容受到影响     | 跟踪失败段落，提供单独重试，不移除成功译文         |
| 服务离线或令牌无效时仍能发起翻译                 | 点击后才失败，缺少下一步指导             | 开始翻译前检查连接；恢复原文不依赖服务器在线       |
| 连接检查没有超时和过期响应保护                   | 网络请求可能一直挂起；旧响应覆盖新状态   | 5 秒超时、取消上一次检查、忽略过期响应             |
| 修改连接参数后依靠失焦自动保存                   | 用户不知道是否保存或验证成功             | 明确的“保存并连接”按钮和结果提示                   |
| 仅译文模式下样式控件只靠 CSS 禁用鼠标            | 键盘仍可能操作不适用的设置               | 使用原生 disabled fieldset，并收起不适用的选项     |
| 安装前已打开的标签页缺少内容脚本                 | 经常要求用户刷新才能使用                 | 使用已有 scripting 权限补注入，并增加重复注入保护  |
| 纯中文或无正文页面可能长时间停在“正在翻译”提示   | 看起来像卡住                             | 发现无英文正文时明确说明；等待滚动不伪装成持续计算 |
| 当前旧服务不返回 authorized 字段                 | 版本不兼容被误认为令牌有误               | 独立显示“服务需更新”，引导从最新项目重启           |

## 新的交互方式

1. **首次打开**：读出当前页标题和域名，同时检查本地服务。需要连接时展开设置，提供启动命令和复制按钮。
2. **配置服务**：输入本地地址和令牌，点击“保存并连接”。仅支持现有权限覆盖的 `http://127.0.0.1:端口` 和 `http://localhost:端口`；令牌仍保存在本机 local storage。
3. **选择阅读模式**：双语对照保留原文，译文样式可选；仅译文模式收起样式选择，悬停译文可查看原文。方向键、Home、End 可切换选项。
4. **开始翻译**：弹窗保持打开，每秒读取一次当前页状态；关闭弹窗不会停止页面内翻译。计数是实际段落数，不展示容易误导的全页完成百分比。
5. **部分失败**：已完成的译文保持可读，显示“重试失败段落”。检查连接后只重试失败内容。
6. **恢复原文**：停止本页监听与排队、移除译文、清空当前计数；迟到的旧请求结果不再插回页面。

“停止并恢复原文”停止的是页面翻译和结果展示；已进入 MLX 推理的服务端任务目前仍会继续计算到返回。这不等于服务端推理取消。
